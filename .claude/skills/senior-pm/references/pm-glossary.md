# PM glossary — key terms across the catalog

Load this for a quick, precise definition of a term used by other skills. Definitions are
deliberately short. Examples reference the running sample project: **Helios**, a customer
self-service portal.

## Stage and governance
- **Charter** — the short document that authorizes a project, names the sponsor and PM,
  and states purpose, scope boundaries, and success criteria. See `project-charter`.
- **Business case** — the justification for the investment: options, benefits, and
  financials (NPV/ROI/payback). See `business-case`.
- **Sponsor** — the single accountable executive who funds the project and owns the outcome.
- **Stage gate** — a formal go/no-go checkpoint between phases (typical of waterfall).
- **Baseline** — the approved version of scope, schedule, and cost that actual progress is
  measured against. Changing it requires change control. See `project-planning`.

## Scope and schedule
- **WBS (Work Breakdown Structure)** — a hierarchical decomposition of scope into
  verifiable work packages. See `work-breakdown-structure`.
- **Work package** — the lowest-level WBS item that can be estimated and assigned.
- **Critical path** — the longest chain of dependent activities; it sets the shortest
  possible project duration. Slip on it slips the project. See `project-schedule`.
- **Milestone** — a dated, zero-duration checkpoint marking a significant event.
- **MVP (Minimum Viable Product)** — the smallest releasable increment that delivers value
  and produces learning. Common in agile/hybrid delivery.

## Estimation and cost
- **Three-point / PERT** — estimate using optimistic, most-likely, and pessimistic values;
  PERT mean = (O + 4M + P) / 6. See `estimation`.
- **Story points** — a relative measure of effort used in agile estimation.
- **EVM (Earned Value Management)** — a method that compares planned, earned, and actual
  value to measure schedule and cost performance. See `cost-management`.
- **CPI (Cost Performance Index)** — earned value / actual cost; < 1 means over budget.
- **SPI (Schedule Performance Index)** — earned value / planned value; < 1 means behind schedule.
- **EMV (Expected Monetary Value)** — probability x impact for a risk; the basis for risk
  scoring. See `risk-register`.

## Roles, risk, and reporting
- **RACI** — a responsibility matrix marking who is Responsible, Accountable, Consulted,
  and Informed for each activity. See `raci-matrix`.
- **RAG** — Red/Amber/Green status rating used in `status-report`.
- **Risk vs. issue** — a risk is a future uncertain event; an issue is a problem happening
  now. See `risk-management` and `project-delivery`.
- **Definition of done (DoD)** — the agreed checklist a work item must meet to be complete.
  See `quality-management`.
- **Benefits realization** — tracking that the value promised in the business case is
  actually achieved after delivery. See `project-closure`.
