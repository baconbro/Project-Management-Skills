# Routing map — situation to skill

Load this to send the user to the right skill. Match the user's situation/intent to a row
and route to the skill in the **Go to** column (name it in backticks). When two fit, prefer
the phase skill for "where do I start" questions and the artifact skill for "make me an X"
questions.

## The 22 catalog skills (one-liner each)
| Skill | What it does |
|---|---|
| `senior-pm` | Diagnose stage/health, recommend methodology, and route (this skill). |
| `project-initiation` | Stand up a project: business case, charter, stakeholder ID, kickoff. |
| `project-planning` | Build the integrated plan: scope/WBS, schedule, estimation, budget, resources, risk, quality, comms, baseline. |
| `project-delivery` | Execute and monitor/control: progress, issues, changes, status, steering. |
| `project-closure` | Close out: acceptance, benefits handover, lessons learned, admin/financial closure. |
| `stakeholder-management` | Identify, analyze, and engage stakeholders (power/interest, engagement). |
| `risk-management` | End-to-end risk process: identify, analyze, respond, govern. |
| `cost-management` | Estimate, baseline, and control budget; earned-value tracking and forecasting. |
| `quality-management` | Acceptance criteria, definition of done, quality gates, review cadence. |
| `project-communication` | Comms plan: audiences, channels, cadence, message tailoring, escalation. |
| `change-management` | Govern change: change-control process and organizational adoption. |
| `project-charter` | Produce a charter that authorizes the project. |
| `business-case` | Justify the investment (options analysis, benefits, NPV/ROI/payback). |
| `work-breakdown-structure` | Decompose scope into verifiable work packages. |
| `project-schedule` | Build/analyze schedule; critical path and dependencies. |
| `estimation` | Estimate effort/duration/cost (analogous, parametric, three-point/PERT, story points). |
| `raci-matrix` | Build and validate a responsibility assignment matrix. |
| `risk-register` | Produce/maintain the risk register and score it by exposure/EMV. |
| `status-report` | Produce concise RAG status reports. |
| `change-request` | Capture and assess a single change request to a decision. |
| `meeting-management` | Run effective meetings: agendas, facilitation, decisions, actions. |
| `lessons-learned` | Capture, categorize, and operationalize lessons. |
