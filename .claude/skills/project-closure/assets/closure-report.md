# Project Closure Report — <Project name>

Fill-in template for step 8 of `project-closure`; it covers all three closure paths (completed
project, phase or stage, stopped early). Keep it to 2-4 pages: it is the permanent record that
the project was accepted (or properly stopped), handed over, closed financially and set up
for benefits tracking. Replace every `<placeholder>`, delete rows and sections marked for a
path you are not on, and compare with `assets/closure-report-sample.md`, the completed report
for the sample Helios project (a fictional customer self-service portal used throughout this
catalog). Run `references/closure-checklist.md` before routing it for signature.
